# 运行与口径说明

## 环境与运行

需要 Python 3.10 或更高版本。运行代码只使用标准库，不需要安装第三方包、读取环境密钥、连接网络或数据库。

```bash
python -m unittest discover -s tests -v
python -m workshop_lab --seed 37 --days 80 --stocks 40 --output artifacts/demo
```

输出目录中若已有同名结果，程序会拒绝覆盖；重复实验请换一个目录。相同参数在同一 Python 环境下应给出相同数值结果；不同平台的浮点数末位不承诺字节完全一致。

## 合成数据

- 股票名称为 `S000` 等虚构标记；价格是固定种子随机过程。
- 日历是连续工作日，不代表真实交易所节假日。
- 示例信号来自已经观察到的五日收盘价变化，另有波动特征用于相关性演示。
- 收盘价与 VWAP 是生成器分别构造的教学价格，不是实际成交。
- 生成器没有用未来收益定义信号；测试检查未来输入扰动不能改变更早的信号。

该信号只为验证接口与时间链设计，不是推荐复现的投资策略。

## 四个虚构投资范围

`FULL` 使用全部合成股票。`WIDE`、`MEDIUM`、`SMALL` 使用不同数量的股票，成员每20个合成交易位置轮换。它们不是全 A 或真实指数数据。

构造信号一次；在信号日应用对应成员资格，再匹配次日入场和后日退出。所有池共享同一天的合成全市场等权收益作为基准。

## 分组与缺失

有效信号按 `(分数, 股票标记)` 排序，近似等分为十组，组内等权。股票标记仅用于并列分数的确定性处理。有效股票少于十只时保留该日期并标为 `insufficient_signals`，不画出虚构收益。

已选股票若缺少必要入场／退出价格，则报错，而不是事后把它从选股名单移除。未知信号可以不参与排序，但不能通过未来收益是否存在来决定选股。

每个有效记账日保存：基准、G1／G10绝对收益、G1／G10超额收益、固定方向H-L、有效股票数量与 Rank IC。恒等式按浮点容差检查。

## 相关性

Spearman 在共同有限值上计算，使用平均并列排名。少于三个共同样本或常量截面返回不可计算，不填零。

跨日统计同时提供有符号均值和逐日绝对值均值；不可把 `abs(mean(corr))` 当成后者。

## 输出不是绩效证明

样例不以年化收益或最高 Sharpe 为目标，不对负结果翻方向；不实现净收益、融资、滑点、税费、实际订单执行或生产中性化。输出的相关性与收益只描述这个合成样本。

测试通过只说明测试覆盖的合成情况符合预期，不能认证真实数据的 PIT、文献复现忠实度、可成交性或实际策略收益。
