# Ten Selected Factors

十个代表性研究对象，采用**英文展示名＋中文介绍**。它们覆盖关系网络、成交行为、波动结构和日内时序，不是根据一张业绩表排序得到的“最强十因子”。

本目录不公开因子源码、精确参数、完整数学实现、逐股数据或真实绩效。这里的名称用于展示，不宣称与某个行业标准代码一一对应；具体研究版本之间的差异不靠名称掩盖。

## 如何阅读

每页区分“实际测量的对象”和“为什么可能有收益的假设”。后者必须接受同口径检验、风格解释和样本外检验，不能仅靠故事成立。

这里不将任何因子标为“已认证可交易”。本次是介绍目录更新，不是新的因子构造、版本择优、四股票池回测或准入决定。

CF详细页只讨论直接关联反转这个研究对象，不把间接关联、组合信号、首次覆盖事件和不同网络更新版本的结果混用。
