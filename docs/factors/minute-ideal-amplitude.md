# Minute Ideal Amplitude

中文介绍：把分钟振幅与其所在的价格位置结合起来看，比较较高价格区域和较低价格区域附近的波动结构。

相同的总体振幅可能来自不同路径：较高价格附近的剧烈交易，与较低价格附近的震荡，不一定具有相同含义。研究关注这种条件差异，而不是只保留一个全天波动数值。

价格用于排序和振幅用于测量，两个角色需要分开；复权、样本缺失和后续市值处理也会影响版本身份。该分钟版本不能直接与日线同名思路混为一项结果。

本页不披露分位比例、窗口、参数、源码。
