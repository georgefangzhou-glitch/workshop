# Residual Non-Isolated Trade Imbalance

中文介绍：把成交放在其周围的交易活动中理解，研究非孤立成交的买卖方向不平衡，而不只比较全天的买入量和卖出量。

研究版本还区分规模和同期价格涨跌的影响，关注处理后是否仍有额外信息。残差表示未被指定变量解释的部分，不等于自动剥离了所有风险，也不保证会提高效果。

研究重点是成交分类是否可靠、必要事件是否完整，以及与短期反转、流动性和规模暴露的区别。它不能仅凭普通分钟成交量推断真实主动买卖，更不能用未来价格反应替代成交分类。

本页不披露事件判定规则、窗口、回归细节、源码、数据接口或真实绩效。
