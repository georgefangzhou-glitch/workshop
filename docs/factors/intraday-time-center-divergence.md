# Intraday Time-Center Divergence

中文介绍：分别考察上涨和下跌发生在日内的什么位置，再研究两者时间重心的相对差异。

同样的全天收益，可能来自早盘上涨后回落，也可能来自早盘承压后尾盘修复。这个研究对象关心过程的先后和集中时段，而不是把重心数值解释为“收益更高”。

共同市场状态与已有日内价格信息可能同时影响两个重心，因此需要区分共同变化和剩余差异。单独的时间重心分项也不能与加入收益偏度后的复合信号混用。

本页不披露控制变量组合、平滑窗口、回归细节、源码。
