# Information Distribution Uniformity

中文介绍：观察日内价格收益波动在不同交易日之间如何变化，研究价格调整是持续发生，还是集中在少数时点或少数日期。

这里的“信息分布”是基于价格过程的统计刻画，不是直接读取新闻，也不证明每一次波动都来自新信息。

研究重点包括分钟收益的真实相邻关系、未知价格是否被错误跳过，以及跨日波动变化是否只是规模或低波动风格的另一种表现。原始统计与市值处理需要分别记录。

本页不披露窗口、阈值、源码、商业分钟数据。
