# Regret-Aversion Buying Volume

中文介绍：观察主动买入的成交发生在什么价格，并以当天收盘时的价格位置来描述这部分交易群体的状态。

例如，一部分主动买入发生在高于最终收盘价的位置，这能形成一个可测量的成交特征。但统计到这类成交，不等于已经观察到投资者真实的心理，也不能直接推出他们下一天一定买入或卖出。

研究重点是实际成交与订单、撤单的区分，主动方向是否有可靠依据，以及盘中成交价与收盘价是否采用一致的价格单位。后续风格正交版本需要另行比较，不能归入原始成交比例的表现。

本页不披露逐笔判定实现、数据接口、参数、源码。
