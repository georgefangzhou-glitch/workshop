# 02 · 分量拆解与增量信息

**研究问题：** 一个复合信号表现不错，究竟是每个分量都贡献了信息，还是某一个分量决定了全部结果？

*English summary: Decompose before combining. Correlation, ablation, and matched-calendar comparisons answer different questions.*

## 拆开三个问题

1. **是否测量相同东西？** 在相同日期、共同有效股票上计算分量之间的截面相关性。
2. **是否增加预测信息？** 比较单项、组合和移除某一分量的版本，而不只看相关性大小。
3. **是否值得交易？** 另外检查换手、覆盖、成本与适用股票池。

低相关不自动意味着高增量；高相关也不自动意味着其中一个没有用。

## 为什么两种“绝对相关”不能混用？

假设两天的相关系数分别是 `+0.8` 和 `-0.8`：

- `abs(mean(corr)) = 0`：描述平均方向抵消后的结果。
- `mean(abs(corr)) = 0.8`：描述每天实际接近程度。

两者回答的问题不同。后者也不能替代有符号均值，所以报告时同时保留方向、有效天数、共同样本数量和具体版本。

## 消融比较的最低要求

使用相同日历、信号可得时点、方向、交易规则、基准和费用。覆盖变化单独说明，不把换了数据源、公式和样本范围的两张曲线解释为某个分量的单独贡献。

在看过结果后选择组合和权重，仍然存在多重试验与选择偏差。一个事后时间切片不能因为被称为“留出期”就变成盲样本外。
