# 01 · 关系网络与信息扩散

**研究问题：** 一组股票被同一批研究者或机构关注，意味着它们共享信息、交易行为，还是仅仅属于相同的行业和规模区间？

*English summary: A coverage network is a hypothesis about information links, not proof of causal transmission. Historical availability and incremental explanatory power come first.*

## 方法说明

将股票看作节点，将可公开解释的共同关注关系看作边。分别讨论直接邻居、间接邻居以及网络自身的集中度，不预设“关系更多”一定更好。

这里只说明研究设计，不公开特定研究的事件记录、关系权重、私有参数或绩效。

## 最重要的时间问题

- 报告对应的财年，不等于报告公开时间。
- 报告日期，不必然等于数据库首次可得时间。
- 用完整历史一次性建网，可能把未来关系提前带入过去。
- 今天的分析师身份、机构归属或股票覆盖，不能无证据地回填历史。

因此，每个网络快照都应能回答：当时已经知道哪些关系？什么时候刷新？何时首次可以交易？

## 希望看到的反证

| 比较 | 想排除的替代解释 |
| --- | --- |
| 网络信号与行业／规模相近的股票比较 | 只是行业或规模暴露 |
| 直接关系与间接关系分别检验 | 所有增量都来自最直接邻居 |
| 打乱关系但保持节点度数 | 关系结构并不重要，只有覆盖数量重要 |
| 同一网络下比较多个时间区间 | 效果只来自一个市场阶段 |

打乱检验也必须保留真实时间可得性，不能为了“对照”而引入未来样本。

## 当前证据边界

本页是方法笔记，不提供真实回测结果，也不宣称已完成上述全部实验。商业来源与受限实现不在此仓库公开。合成样例只覆盖通用的时序和相关性检查，不实现这类网络因子。
