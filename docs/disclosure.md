# 公开内容与研究贡献

本仓库展示 George 的系统化选股研究：从公开研究思路出发，推进数据核查、信号实现、实验比较、时序修正与结果解释。真实研究成果与可运行的合成教学样例分别标记。

## 本次公开的成果

- 六个真实历史研究案例，每个保留四张原始回测图；另有一张期货交割事件研究图。
- 精选图片对应的汇总指标，以及跨股票池实验的研究说明和代表性对照。
- 研究覆盖、实验设计、技术栈、十个代表性因子的高层说明。
- 独立编写、使用虚构数据的教学代码与自动测试。

原始图未经重绘或修数。图集属于择优后的回顾性展示，采用未扣交易成本的毛收益，不是实盘或独立盲测成绩。具体股票池、日期、交易记账与共同基准见[结果图集](results/README.md)。原图内的费用估算文字不代表费用已经从收益中扣除。

## 保留在私有研究环境的内容

真实因子构造源码、精确实现参数、逐股因子面板、商业行情、数据库查询、连接配置、凭证、内部运行记录、持仓与研报全文均不发布。公开的聚合结果不能还原逐股信号，也不能仅凭克隆仓库独立复现真实策略。

## 来源与个人工作

公开研报与论文提供部分原始研究思路；真实回测复用既有公司框架。个人研究工作集中于问题定义、数据与价格口径、实现核对、分量拆解、风格与股票池对照、错误定位及结果判断，不将原始研报思想或公司公共框架称为个人原创。

代码与文档使用AI辅助开发和整理。合成教学代码独立于真实因子实现，用于展示可解释、可测试的研究工程方法。

## 证据范围与许可

不同案例的历史数据可得性认证、成本与容量检验程度不同；不以一个案例替其他案例背书。研究范围页明确区分正式历史回放、观察性事件研究与探索任务。

本次仅从明确的公开文件清单发布。可见性不等于授予商业数据、研究方法或代码的额外复用许可；仓库尚未选定开源许可证。如需合作或复用，请通过GitHub Issues交流。
