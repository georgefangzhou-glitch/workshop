# 公开内容边界

## 本仓库可以看到什么

- 独立撰写的研究问题、实验设计与局限说明。
- 独立编写、只依赖 Python 标准库的教学样例和自动测试。
- 从零生成的合成数据，以及生成规则和固定随机种子。
- 当前实际实现的能力与没有实现的部分。
- 经用户确认公开的十个英文因子展示名、中文高层介绍，以及研究环境与流程说明。

## 本仓库不包含什么

没有公司源代码、生产配置、数据库查询、账号凭证、商业行情、逐股因子面板、真实持仓、内部运行日志、真实相关性矩阵或研报全文。

真实结果未公开时直接说明，不通过改数、匿名股票或画一条看似真实的曲线来替代披露授权。合成数据不是从真实数据抽样或匿名化得到的。

## 来源、贡献与许可

研究主题是公开研究领域的通用问题，不宣称独占这些思路。若后续增加具体文献复现，将分别标注原始文献、公开允许的实现范围和自己的改动；不上传无权分享的材料。

本版样例与文档使用 AI 辅助编写。代码可在本地检验，维护者仍需能够解释其逻辑、假设与局限。

本仓库暂未选定开源许可证；可见性不等于已授予不受限制的使用、修改或分发权。如有复用需要，请先交流。

## 发布约束

仅从公开文件白名单发布，不上传父研究目录或其历史。实际提交只包含本仓库的独立文档、样例和测试。

本次因子展示仅增加名称与介绍，不增加真实因子源码、精确参数、数据接口、环境镜像或绩效。CF详细页解释直接关联反转的研究逻辑，不提供实现，亦不把文献与其他研究版本的结果冒充本页实证。

原有合成教学源码与真实因子实现分开；它不构造本次展示的十个因子。新增真实图表、绩效、联系方式或受限方法，需要另行核实允许披露的范围。自动扫描不是授权，也不能替代人工审查。

当前未启用 GitHub Actions、Pages 或其他外部部署，不把文档中的计划描述成已经完成的服务。
