## Evaluation Conventions

- 信号每日生成、收益逐日记账；关系网络等底层依赖的刷新规则不等于价格信号刷新规则。盘后信号，下一交易日全天VWAP进场，再下一交易日VWAP退出，收益按退出日标记。
- 每个因子的三个历史指数池保留同一构造与处理方式，只改变投资资格；不是按今天的成分股回溯。信号有效股票数不保证等于指数名义只数。
- G10是预先固定方向的多头端，H-L=G10-G1。原生Direction统计文字不替代带符号结果，不因负表现翻转方向。
- 年化为日均收益×250，不是CAGR；Sharpe按250日、零无风险利率。均为fee=0毛收益，未扣佣金、税费、滑点、冲击和融券成本。图中费用提示不是已扣费用。
- 三池共同基准是中证1000官方历史权重下的日VWAP研究序列，除数由官方收盘指数反推，不是官方发布的VWAP指数；500、300超额仍相对该1000基准。
- 原生分层图为累计日收益加总，柱图为平均日收益；双面板为复合净值，回撤为G10超额日收益复利净值的回撤。
- 前八个因子的本组三池区间为2018-10-17—2025-09-30（1692日）；换手增长稳定性为2020-01-06—2025-09-30（1393日）；主动买量比例为2018-10-08—2025-09-30（1699日）。不缩短或拼接原图。
- 换手增长稳定性三池为仅规模处理，旧全A精选为行业＋规模版本；不能把两者直接解释成股票池导致的差异。
- 原PNG按字节保留并与交付哈希核对，没有重画、更改方向或删除不利时期。没有发布逐股持仓、因子面板、商业行情或公司实现。
- 部分指数池临时数值表已按既定存储政策清理，保留图、汇总和审计证据；本仓库的图与CSV不是可独立复现完整策略的数据包。
- 历史数据可得性、交易可实现性、成本容量和独立入库审查仍需各自证据；这次整理不升级原实验的认证状态。
