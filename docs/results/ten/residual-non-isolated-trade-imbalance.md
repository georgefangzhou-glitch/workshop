# Residual Non-Isolated Trade Imbalance

反转残差非孤立成交不平衡。 每日信号研究版，保留市值及同期收益残差处理；不是原研报月末信号版本，也不是行业＋规模中性版本。

**历史毛收益，未扣交易成本；回顾性研究结果，不是独立盲测或实盘。** 三池共同使用中证1000官方历史权重的日VWAP研究基准，500/300的超额不是相对自身指数。
