# Turnover Distribution Uniformity

换手率分布均匀度。 20日版本，规模处理；不是40日版本。

**历史毛收益，未扣交易成本；回顾性研究结果，不是独立盲测或实盘。** 三池共同使用中证1000官方历史权重的日VWAP研究基准，500/300的超额不是相对自身指数。
