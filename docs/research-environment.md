# Research Environment

这是一份研究环境与工作方式说明，不是公司环境镜像、数据库接入教程或因子源码发布。

## 技术栈与分工

| 层次 | 使用的技术与工作方式 | 主要作用 |
| --- | --- | --- |
| 本地研究 | Windows、VS Code、Jupyter | 阅读资料、检查样本、交互分析与整理研究说明 |
| 远端计算 | Linux、Python、分批与并行任务 | 运行较长历史区间的构造、验证与结果分析 |
| 数值研究 | NumPy、pandas、统计回归工具 | 时间序列与横截面运算、分量比较、风险暴露分析 |
| 数据组织 | DolphinDB、SQL数据库、Parquet与CSV | 在授权环境中处理多源数据，保留输入与结果的身份 |
| 结果检查 | 分组、相关性、收益口径核对、图表 | 检查排序能力、适用范围与实现一致性 |
| 版本管理 | 参数与数据版本记录、文件哈希、完成状态 | 区分原始实现、修正、研究变体和未完成任务 |

这里只列技术类别，不公开服务器地址、数据库表结构、查询语句、凭证、部署脚本或生产配置。项目实际依赖的商业环境不能仅通过克隆这个仓库获得。

## 研究数据的角色

研究涉及日频行情、分钟或逐笔交易、分析师覆盖关系、行业与规模信息等。不同因子使用不同输入，不把所有字段强制套在每一个因子上。

尤其区分三件事：

1. **因子原始输入：** 用什么信息定义研究对象。
2. **信号内部的价格或收益：** 公式里需要收盘价、开盘价、分钟价格还是其他口径。
3. **组合交易与记账：** 用什么交易窗口、成交价假设和收益日期衡量结果。

组合按VWAP记账，不意味着所有因子公式里的价格也要改成VWAP。

## 一次研究如何推进

| 阶段 | 要回答的问题 |
| --- | --- |
| 定义研究问题 | 测量什么现象？预期方向是什么？有哪些替代解释？ |
| 核查数据 | 字段、单位、历史覆盖与当时可得性是否支持这个定义？ |
| 构造与版本锁定 | 窗口、方向、后处理和计算频率是否明确？ |
| 小样本验证 | 时间顺序、缺失、边界、覆盖和分组是否符合预期？ |
| 同口径评估 | 分层、IC、长端超额、回撤和换手是否能互相解释？ |
| 增量与反证 | 剥离了什么？改变股票池后还成立吗？是否只是已有风格暴露？ |
| 记录与复核 | 哪些检查通过，哪些缺证据，哪些只是研究假设？ |

未知值不作为零收益补上，不靠删除不利日期改善图形；对同一因子的不同版本保留区分，不把换公式或换频率描述成简单修复。

## 当前标准评估规范

下表描述后续研究的默认规范，不代表目录中的每个因子都已完成全部检验。

| 项目 | 约定 |
| --- | --- |
| 投资范围 | 全A、中证1000内、中证500内、沪深300内四套；指数池采用信号日的历史成分 |
| 因子可比性 | 同一选定构造与中性化版本保持不变，只改变最终投资资格 |
| 共同基准 | 中证1000历史计算权重下的日VWAP研究基准；不是各股票池自己的指数基准 |
| 成交与记账 | 默认收盘后信号，下一交易日VWAP入场；按退出日标记的收益与信号相隔两个交易位置 |
| 图表 | 十组分层、分组均值、长端与基准、相对回撤四类 |
| 指标 | 固定方向H-L Sharpe、长端绝对Sharpe、Rank IC、ICIR、超额年化、回撤、换手与覆盖 |
| 资源与存储 | 有边界的并行、内存检查、失败隔离、可追溯的结果与必要归档 |

采用毛收益时明确未计成本，不把理论全天VWAP当成已证明可以实际成交；历史有效成分区间也不自动证明当时公告或入库时间。

## 版本标签不是处理方式本身

`raw`、`core` 等名称只能辅助定位，不能代替操作链。有的核心版本保留原公式，有的已经包含市值处理或收益率残差。横截面排名也不等同于行业或市值中性化。

不同版本的比较，必须同时说明构造、频率、后处理、股票池、日期和交易口径；本页不公开内部版本清单或真实因子值。

## 公开范围

- 可公开：技术栈、研究流程、英文因子名、中文介绍及原有独立合成教学样例。
- 不公开：真实因子源码、实现参数、商业数据、数据库接入、完整研究环境、真实交易信号与未批准的结果。
- 本仓库不能独立复现真实因子；[合成教学样例](reproducibility.md)只验证通用工程问题。
